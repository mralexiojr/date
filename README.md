# Приглашение на свидание

Статичная страница на шесть экранов. Открывается по ссылке с телефона.
Без сборки, без зависимостей, без Node. Чистые HTML, CSS и JavaScript.

## Что где лежит

```
index.html                  разметка шести экранов
event.ics                   событие для кнопки «Добавить в календарь»
assets/css/styles.css       оформление, тёмная тема, адаптив
assets/js/invitation.js     ВЕСЬ ТЕКСТ И НАСТРОЙКИ вверху файла
assets/fonts/               шрифт Onest, лежит локально
assets/img/place.webp       фото крыши
```

## Что осталось необязательным

**Фото на обложку.** Поле `coverPhoto` пустое, поэтому первый экран сейчас
чисто типографский: заголовок и кнопка. Это выглядит законченно, менять
не обязательно. Если захочешь добавить, положи вертикальный файл в
`assets/img/` и впиши путь в `coverPhoto`.

## Если меняешь дату, время или адрес

Их **три** места, поправить надо все:

1. `CONTENT` в начале `assets/js/invitation.js` — текст на экранах
2. `event.ics` — кнопка «Добавить в календарь». Строки `DTSTART` и `DTEND`
   в формате `ГГГГММДД T ЧЧММСС` по московскому времени
3. Блок `<noscript>` в начале `index.html` — запасной текст на случай,
   если скрипт не выполнится. Он намеренно не берёт данные из настроек,
   иначе не смог бы работать без скрипта

Пропустишь второй пункт, и календарь добавит старое событие. Пропустишь
третий, и в редком случае она увидит устаревшие данные.

## Кнопка «Нет»

По умолчанию уворачивается семь раз, потом даёт себя нажать и ведёт на
спокойный экран без обиды. Настраивается полем `dodges`:

- `dodges: 7` — как сейчас
- `dodges: 9999` — поймать невозможно, классический вариант тренда

Работает и мышью, и пальцем. На телефоне нет наведения, поэтому уворот
висит на `pointerdown`, который срабатывает раньше нажатия.

## Как выложить в интернет через GitHub Pages

1. Создай на GitHub новый репозиторий, например `date`. Публичный.
2. В этой папке выполни:

```bash
git init && git add . && git commit -m "invitation"
```

3. Привяжи репозиторий и отправь код. Подставь свой ник вместо `USERNAME`:

```bash
git remote add origin https://github.com/USERNAME/date.git && git branch -M main && git push -u origin main
```

4. На GitHub открой репозиторий, зайди в **Settings**, слева **Pages**.
   В блоке **Build and deployment** выбери source **Deploy from a branch**,
   ветку `main`, папку `/ (root)`. Сохрани.
5. Через минуту-две страница будет доступна по адресу
   `https://USERNAME.github.io/date/`.

Ссылка открывается в Telegram и в любом браузере на айфоне. Именно поэтому
хостинг нужен: локальный `.html` файл Telegram открыть не даст.

Захочешь адрес покрасивее, положи те же файлы на Netlify перетаскиванием
папки. Node для этого не нужен.

## Кнопка «Добавить в календарь»

Ведёт на `event.ics`. На айфоне переход по такому файлу открывает системный
лист «Добавить событие»: она нажимает «Добавить», и свидание в календаре
вместе с напоминанием за два часа.

Ссылка намеренно без атрибутов `download` и `target="_blank"`. С ними Safari
сохраняет файл в «Загрузки» вместо того, чтобы открыть календарь.

**Важно про Telegram.** Встроенный браузер Telegram файлы `.ics` обрабатывает
непредсказуемо: может открыть календарь, а может ничего не сделать. Если она
нажмёт и ничего не произойдёт, достаточно открыть страницу в Safari через
меню «...» в углу. Кнопка «Написать тебе» работает в любом случае, так что
без календаря договориться всё равно получится.

Работает это только после публикации на GitHub Pages. Локально, по файловой
ссылке, календарь не откроется: браузеру нужен заголовок `text/calendar`,
который отдаёт сервер.

## Проверено

- iPhone: высота экрана через `100dvh`, отступы под вырез и домашнюю
  полосу через `env(safe-area-inset-*)`, тап не подсвечивается и не зумит
- Тема зафиксирована тёмной и одинакова на всех телефонах. Переключается
  в начале `assets/css/styles.css`: там два блока цветов, активен тот, что
  не закомментирован
- `prefers-reduced-motion`: анимации и конфетти отключаются
- Фото грузятся плавно, при отсутствии файла показывается заглушка
