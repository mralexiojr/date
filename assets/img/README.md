# Фотографии

Положи сюда два файла с ровно такими именами:

| Файл | Где показывается | Пропорции | Что снимать |
|---|---|---|---|
| `cover.jpg` | Первый экран, обложка | вертикально, 4:5 | Вертикальный кадр. Ваше общее фото или что-то, что она сразу узнает |
| `place.jpg` | Третий экран, место | горизонтально, 3:2 | Крыша, экран, вид с Taganka Roof |

## Размеры

Ужми до 1600 px по длинной стороне. Больше не нужно: страницу открывают
с телефона, а тяжёлые файлы на мобильном интернете грузятся заметно.

## Другие имена

Если удобнее свои названия, поменяй пути в начале файла
`assets/js/invitation.js`, в полях `coverPhoto` и `placePhoto`.

## Пока фото нет

Страница не сломается. На месте фотографии будет мягкая тёплая заглушка
с подсказкой, какой файл сюда положить.
